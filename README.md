# OnlineStore

Это тестовый проект онлайн-магазина, разработанный с использованием ASP.NET Core на серверной стороне и Vue.js на клиентской стороне.  
Проект предназначен для улучшения навыков разработки и изучения новых технологий.

## Функциональность

### От лица заказчика:

- Регистрация
- Просмотр товаров, фильтрация по категории
- Добавление и удаление товаров из корзины, редактирование количества единиц определенного товара
- Актуализация цен в корзине, оформление и отмена заказа

### От лица администратора:

- Регистрация, удаление пользователей и редактирование их данных (заказчиков и администраторов)
- Просмотр товаров, фильтрация по категории
- Добавление и редактирование товаров
- Просмотр, редактирование, оформление и отмена заказов

### Стек технологий

- **Backend**: ASP.NET Core
- **Frontend**: Vue.js
- **База данных**: PostgreSQL
- **ORM**: Entity Framework Core
- **Контейнеризация**: Docker
- **Тестирование**: xUnit

## Установка и запуск

1. **Клонирование репозитория**

_git clone https://github.com/Yuskus/OnlineStoreAspVue.git_

2. **Настройте переменные окружения**

_Найдите файл **public.env**. В нём есть все переменные окружения. Заполните их своими данными после знака равно. Приватный ключ хранится конвертированный в base64, так как строки с переходами на следующую строку неправильно считываются. В конце не забудьте **переименовать public.env в .env**._

3. **Запустите проект**

- _Для запуска на **Windows** нужно включить **Docker Desktop**. Когда он будет включен, запустите файл runner.batch._

- _Для запуска на **другой ОС** необходимо поднять контейнеты с использованием двух **docker-compose** файлов: для backend файл находится в корневой директории, для frontend - внутри frontend-проекта (относительный путь: "./onlinestore.client")._

## Использование

После запуска получить доступ к OnlineStore можно по адресам:
- [http://localhost:5000](http://localhost:5000) (backend, swagger)
- [http://localhost:5777](http://localhost:5777) (frontend)
